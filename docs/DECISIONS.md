# Decisions and findings (append only, one short entry each)

- **2026-11-21 A: renderer modules, no bundler.** Renderers are plain `<script type="module">` over `file://` (works in Electron 45, verified by `npm run selftest`). Bare `@huggingface/transformers` resolves through an `<script type="importmap">` in each HTML page, pointing at `node_modules/@huggingface/transformers/dist/transformers.js` (the `.web.js` build has bare `onnxruntime-web/webgpu` imports that would need more map entries). Main process is Node ESM (`"type": "module"`); preload is `preload.cjs` because sandboxed preloads must be CommonJS.
- **2026-11-21 A: network is blocked at runtime.** `src/main/main.js` cancels every http(s)/ws request from renderers unless `SHIELD_ALLOW_NETWORK=1` (dev only, e.g. first model download). Agent C: Transformers.js/ORT fetch WASM files from a CDN by default, so point `env.backends.onnx.wasm.wasmPaths` at `../../node_modules/onnxruntime-web/dist/` and set `env.allowRemoteModels = false`, `env.localModelPath` to `models/`.
- **2026-11-21 A: install scripts.** npm 12 blocks dependency install scripts. `onnxruntime-node` and `protobufjs` are denied in `package.json` `allowScripts` (we use the web ONNX runtime, not the Node one). Electron's binary downloads normally.
- **2026-11-21 A: hotkeys.** Reveal 5 s: `Cmd/Ctrl+Alt+R`. Shield on/off: `Cmd/Ctrl+Alt+S`. Open settings: `Cmd/Ctrl+Alt+,`. Defined in `HOTKEYS` in `src/main/main.js`.
- **2026-11-21 A: Settings object** (not spelled out in INTERFACES.md): `{ enabled, activeProfileId, profiles: { [id]: Profile } }`, defaults in `src/shared/profiles.js` (`defaultSettings()`). Persisted to `<userData>/settings.json`. `settings:set` does a shallow merge of the top-level keys, so send the whole `profiles` object when editing a profile.
